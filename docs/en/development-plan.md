# Delivery cycle and remaining gates

Delivered locally: contract/schema, strict loader/validator, conservative diff, static HTML, two explicit adapters, fixtures/tests, package configuration, paired documentation and executable guide checks. One project cycle ends with validated install artifacts plus exact-head CI, reviewed merge and alpha release. Local evidence must not be relabeled as hosted CI.

Before release: inspect public package contents; run all CI platforms on the precise commit; verify wheel/source installation; audit pinned dependencies; publish alpha with limits. Follow-up work: adapters for Guard extended envelopes and other auditors, broader malformed-producer corpus, migration policy and independent evidence authenticity. Add each adapter only after reading actual source formats.

No automated infrastructure collection, remediation, online token checks or real AD lab is part of this project. A documentation count is not an acceptance criterion: commands, schema examples and actual status semantics are checked.
