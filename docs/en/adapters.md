# Inspected producer adapters

Guard: core response-0.2 only. Its bundled source schema and budget/coverage/stop consistency are checked. Repeated findings with the same check/asset are grouped into one record with unique line refs; >128 refs reject conversion. Fail statuses remain fail. No passes are inferred. A finding_only_source gap always remains because the source does not enumerate every performed check/asset pair. Operator supplies scope, UTC observation time and synthetic class explicitly.

AD: report_schema_version=1 inspected at commit 6c5687f7ffe0f57825bb29ff86453c6b4e9a914e, report.py/rules.py. Source summary, statuses, complete pass/fail coverage, evidence membership and input-hash syntax are checked. unknown and not_run become not_tested; pass/fail remain explicit. Scope, synthetic flag, engine/rules version and observation time are retained. Evidence IDs become SHA-256 references; raw reasons/evidence descriptions/remediation are omitted in favor of generic guidance. Hashing identifiers is not anonymization or provenance verification.

The AD fixture was generated by that producer code from its safe.synthetic.json; it is not a real AD export or Windows test. Mapping is deliberately lossy. Unknown future formats require a new adapter and corpus; core Guard only means its bundle/Office/secret envelopes are currently rejected.
