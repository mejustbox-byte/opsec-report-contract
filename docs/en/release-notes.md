# Local alpha candidate 0.1.0a1

Delivered contract opsec-1.0, strict bounded validation, status/coverage-safe diff, static escaped HTML and inspected Guard/AD adapters. Includes 16 local test methods and bilingual product guides. Distribution is configured as a Python wheel/source package under MIT.

Current evidence is local Linux/Python 3.12, synthetic source reports and clean installation. Hosted three-OS CI, public GitHub release/tag and PyPI publication have not been completed. This candidate does not authenticate producer assertions or real AD state. Guard core normalization is finding-only and always retains an incompleteness marker; other Guard envelopes are unsupported.

Residual limits: no hard process quotas, source signature verification, automatic privacy sanitization, remediation or network audit. Diff absence is not fixed; HTML escape is not disclosure approval. Versions/rules/scope changes make comparison incompatible.
