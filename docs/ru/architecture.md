# Архитектура и поток данных

CLI → ограниченная UTF-8 загрузка → явный адаптер производителя → локальная схема → межполевые условия → общий JSON/сравнение/статический HTML. Функции ядра работают со словарями; чтение и эксклюзивная запись отделены. Нет сетевого сборщика, API, базы и фоновой службы.

Лимиты: 8 000 000 байтов, глубина 64 до разбора JSON, 10 000 результатов/пробелов, длины полей и 128 ссылок на запись. Это границы входа/структуры, не жёсткие квоты RAM/CPU. Зафиксированные jsonschema/referencing не получают схемы из сети. Ошибки не подменяются успехом.

HTML — статический текст/локальный CSS с экранированием и CSP default-src none, base-uri none, form-action none. Управляемые входом ссылки/изображения/скрипты не создаются. Выход создаётся эксклюзивно, симлинки отклоняются. Существующие файлы не перезаписываются. Пути/текст могут быть чувствительны даже после обезвреживания markup.
