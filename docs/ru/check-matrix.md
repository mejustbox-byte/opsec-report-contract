# Матрица проверок

R1: загрузка/схема/типы/redaction/даты/байты/глубина. R2: четыре статуса, пустая область, дубликаты идентичностей, противоречия сводки/покрытия. R3: исчезновение, явный pass, потеря покрытия, разные контексты. R4: script/image-контрольные строки, CSP/отсутствие сети. R5: отчёт настоящего AD-производителя, unknown, отсутствие pass-inference Guard, противоречия источника. R6: CLI/эксклюзивный выход; чистая установка отдельно. R7: пары документов/ссылки и выполняемые синтетические примеры.

Шестнадцать unittest-методов проходят локально на Linux/Python 3.12 с фиксированными зависимостями. Подготовленная CI-матрица задаёт Linux/Windows/macOS/Python 3.13 после запуска; выполненной она не объявляется. Минимальные фикстуры не проверяют Windows AD. HTML-тесты не являются полным доказательством защиты браузера. GitHub release и PyPI пока отсутствуют.

Источники: AD-коммит 6c5687f7ffe0f57825bb29ff86453c6b4e9a914e, основной response-0.2 Guard 0.3.0a1. Это идентификаторы изученных структур, а не подписи/реальное состояние инфраструктуры.
