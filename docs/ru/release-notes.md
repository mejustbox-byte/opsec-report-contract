# Alpha 0.1.0a1

Поставляются opsec-1.0, строгая ограниченная валидация, сравнение без потери статусов/покрытия, экранированный HTML и изученные адаптеры Guard/AD. 16 локальных тестовых методов и двуязычные руководства. Настроены Python wheel/исходный пакет с MIT.

Проверены локальные Linux/Python 3.12 и hosted Linux, Windows, macOS/Python 3.13: тесты, выполняемые примеры и чистая установка wheel. CI 38215189151 прошёл на коммите 26ee26d3d1b094e8fbfe7e717862e31faf4c7742. Отчёты синтетические. Релизные файлы собирает prerelease workflow; публикация PyPI вне этой alpha. Кандидат не удостоверяет утверждения производителя/реальную AD. Нормализация Guard только finding-only и всегда сохраняет неполноту; другие ответы Guard не поддержаны.

Ограничения: нет жёстких квот процесса, проверки подписей, автоматической очистки приватности, исправлений и сетевого аудита. Исчезновение не равно исправлению, HTML-экранирование не разрешает публикацию. Изменение версий/правил/области делает сравнение несовместимым.
