# Архитектурные решения

ADR-001 принято: Python 3.12+ и фиксированный jsonschema вместо собственного полного интерпретатора схем. Draft 2020-12 задаёт структуру; дополнительные условия проверяют счётчики/покрытие/идентичности. Версии не заменяют фиксацию хешей цепочки поставки.

ADR-002 принято: четыре статуса и консервативная идентичность. Нет pass из отсутствия находки. Сравнение требует прежних производителя/правил/области/synthetic-класса; обходы давали бы неверный смысл и не поставляются.

ADR-003 принято: статический экранированный HTML вместо сервера. Нет передачи документов и CDN. ADR-004 принято: явно названные адаптеры сохраняют состояние и по умолчанию отбрасывают исходный narrative. Контракты производителей не меняются. Полная специфичная валидация источников и криптографическое происхождение остаются в плане.
