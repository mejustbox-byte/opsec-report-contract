# Контракт opsec-1.0

Обязательные поля: schema_version, producer(name/version/ruleset), run(id/scope/observed_at/synthetic), coverage_complete, summary, results, coverage_gaps. Время — ISO UTC с Z; календарь проверяется. Дополнительные поля отклоняются. Схема включена в пакет и не загружается из сети.

Статусы: pass — явно заявленная успешная проверка; fail — находка; not_tested — недоступно/неизвестно/не запущено; not_applicable — явное решение о неприменимости. Сводка точно считает четыре состояния. Полнота требует непустого списка, отсутствия пробелов и not_tested. Набор только not_applicable полон в своей декларации, но не доказывает выполненные проверки. Отсутствие никогда не создаёт pass.

Пара (check_id,asset_id) уникальна. Запись содержит до 128 различных ссылок. redacted обязан быть true; refs — непрозрачные строки, переходы не выполняются. Redacted — утверждение, а не автоматическая очистка сообщений. Версия производителя/правил определяет совместимость сравнения. Личность источника, подписи, хеши и правдивость свидетельств не удостоверяются.
