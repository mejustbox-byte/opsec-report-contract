# Назначение и приёмка

Продукт задаёт общий язык результатов и локальные инструменты потребителя, а не сборщик инфраструктуры. Запись имеет стабильную пару check/asset, один из четырёх статусов, критичность, сообщение, рекомендацию и скрытые ссылки на свидетельства. Неизвестная схема, неверный JSON и противоречивые утверждения отклоняются. Пустой отчёт остаётся неполным.

Критерии: R1 строгая схема/загрузка; R2 вычисленная сводка/покрытие; R3 консервативное сравнение; R4 экранированный автономный HTML; R5 адаптеры по реальной структуре производителей; R6 установка CLI со схемой; R7 двуязычные выполняемые примеры. Источники неизменны, выход создаётся эксклюзивно. Команды исправления, внешние сервисы и динамические плагины не выполняются.

Alpha охватывает основной Publication Guard response-0.2 и AD report_schema_version=1. Общие/документные/секретные ответы Guard и остальные аудиторы требуют следующих явных адаптеров. Производители не меняются. HTML/отчёты могут содержать идентифицирующие asset/scope/message и требуют отдельной проверки публикации.
