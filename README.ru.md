# OPSEC Report Contract

**Версионированный JSON · Четыре честных статуса · Сравнение покрытия · Статический HTML**

Локальный контракт результатов и набор инструментов OPSEC-аудиторов. Явные pass/fail/not_tested/not_applicable, строгая валидация и сравнение, которое не называет исчезнувшую находку исправленной. Два изученных адаптера сохраняют неопределённость источника, а не создают pass.

**Alpha 0.1.0a1.** CI на Linux, Windows и macOS прошёл с Python 3.13, включая чистую установку wheel вне исходников. Нормализация не доказывает подлинность производителя и безопасность реальной инфраструктуры.

[English](README.en.md) · [Руководство](docs/ru/index.md) · [Установка/примеры](docs/ru/user-guide.md) · [Контракт](docs/ru/contract.md) · [Адаптеры](docs/ru/adapters.md)

```bash
python3 -m pip install .
opsec-report validate examples/after.json
opsec-report diff examples/before.json examples/after.json --output comparison.json
opsec-report html examples/before.json --output report.html
```

Коды: 0 — завершённая область, 1 — находки, 2 — неполнота/несовместимый diff, 3 — ошибка входа/выхода/runtime. Ноль diff означает совместимость, а не отсутствие риска. HTML сохраняет код оценки. Существующие выходы не перезаписываются.

Шестнадцать локальных unittest-методов проверяют статусы/покрытие, строгий разбор, сравнение, HTML, адаптеры и CLI. Примеры синтетические. Guard — основной response-0.2, AD — report schema 1. Другие форматы/аудиторы в плане. Нет сетевого сборщика, автоматического исправления и очистки приватности.
